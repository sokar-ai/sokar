# F02 — Project Overview

**Status:** open

The list of projects, each carrying enough to decide whether it needs attention
without opening it.

## Acceptance

- Each project shows its name, its security class, whether its environment is
  prepared and usable, and how much work it currently has.
- A project whose copy of the upstream has fallen behind says so, and says by how
  much.
- A project holding work that is waiting for review says so.
- A project that is misconfigured or unusable is listed and marked as such, never
  silently omitted.
- The list reflects what changed elsewhere without the person asking for a refresh.
- Selecting a project never changes anything about it.

## Notes

This and [Task Control](F09-Task-Control.md) cover the same machine from two sides: this one
answers "what do I have", the other "what needs me now". Both views exist. The central
requirement this used to narrow has been retired into this set.
