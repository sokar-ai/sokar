# F04 — Guided Project Creation

**Status:** open

A new project described, checked and made runnable without leaving the interface,
including the parts that are easy to get wrong.

## Acceptance

- Every question is asked in one place, with defaults filled in from what the machine
  already knows.
- Answers are validated as they are given, with the reason stated where one is
  rejected.
- The resulting project definition is shown for review, and can be edited by hand,
  before anything is created.
- The flow can be abandoned at any point without leaving a half-created project
  behind.
- On completion the project is either runnable, or the remaining steps are named.

## Notes

Same questions, same vocabulary and same validation as the CLI's own wizard, so a project
created here is indistinguishable from one created any other way.
