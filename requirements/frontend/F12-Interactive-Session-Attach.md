# F12 — Interactive Session Attach

**Status:** open

Getting inside running work to drive it by hand, and getting back out.

## Acceptance

- An interactive session with running work is one action from where that work is
  listed.
- The interface adapts to the person's environment: where an existing session can hold
  both, the overview stays visible alongside the session; where it cannot, the
  interface stands aside and returns intact when the session ends.
- Leaving a session returns to the same place in the interface, with the same
  selection.
- Several sessions against different pieces of work can be open at once, and it is
  always clear which is which.
- A session that cannot be opened says why.

## Notes

The requirement here is the return path: an interface that cannot be got back to reliably is
one people stop leaving. Attaching itself is the domain's, and detaching leaves the work
running.
