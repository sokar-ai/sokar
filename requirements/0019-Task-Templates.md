# 0019 — Task Templates

**Status:** open

The same few jobs recur. A template names one, carries its prompt, and records the
settings that job needs.

## Acceptance

- Templates are definable per project and shared with it.
- Starting from a template is a single action.
- The prompt is editable before it runs.
- A template cannot raise the project's security class.

## Notes

Lower priority than everything above it: valuable, but it automates a thing that
already works.
